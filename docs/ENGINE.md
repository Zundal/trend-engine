# 엔진 로직 — 우리만의 것 vs 가져다 쓴 것

데이터 자체(검색량·뉴스·영상 목록)는 공개 소스에서 가져온다. **이 엔진의 가치는 그 원재료를 어떻게 합치고 해석하느냐**에 있다.
아래는 이 저장소에서 직접 설계·구현한 로직이다. 각 항목은 코드 위치와 테스트를 가진다.

## 0. 테마 묶기 — `scoring.build_themes`
- 같은 이야기(아시안게임 개막 + 나고야)를 한 줄로 접는다. 병합 근거는 셋 중 하나: **단어 단위 포함**, **같은 관련 기사**, **한 제목에 동시 등장**.
  글자 겹침만으로는 묶지 않는다(마크 / 마크롱, 아이폰16 / 아이폰17 분리 유지 — 테스트로 고정).
- 점수 = 대표 + 0.25 × 나머지. 추적 키워드는 20 → 50개, 카테고리당 최대 4개로 분산.

## 1. 교차 검증 트렌드 점수 + 신규성 — `scoring.py`
- 여러 소스의 키워드를 **한국어 표기 차이까지 병합**(띄어쓰기·문장형 헤드라인·단어 겹침; `normalize.py`).
- 점수 = (소스 신호 + 콘텐츠 언급) × **독립 확인 보너스**.
- **소스 패밀리**: 같은 원천을 베끼는 소스(포털 실시간 2곳)는 둘 다 떠도 "독립 확인"으로 치지 않는다 — 흔한 다중소스 랭킹의 과대평가를 막는 장치.
- **신규성**: 지난 30일 중 순위에 있던 날의 비율(친숙도)만큼 점수 × (1 − 0.6 × 친숙도) → 방송사 위키·날씨 같은 단골을 내리고 새로 뜨는 것을 올림.
- 테스트: `tests/test_scoring.py`, `tests/test_normalize.py`

## 2. 연령 affinity — 기준어 정규화 — `segments.py`
- 네이버 검색 데이터는 요청마다 최댓값=100으로 재정규화되고 5개 그룹만 받는다 → 원래는 20개 키워드의 연령 비교가 불가능.
- **기준어(날씨)를 모든 요청에 끼워** 배치 간 비교를 가능하게 하고, 그룹 내 비중 / 전체 비중 = affinity(100=평균)로 환산.
- 테스트: `tests/test_segments.py` (손계산 대조)

## 3. 10·20대 발견 — `youth.py`
- "오늘 뉴스 이슈를 연령별로 재는 것"이 아니라, **후보 풀을 넓힌 뒤**(이슈 + 인기 영상 태그 + 10·20대 쇼핑 고유어) 검색 데이터로 측정.
- 지표: **30대 이상 대비 배수** (`affinity_g / affinity_30대이상`) — 청소년·청년이 *유독* 찾는 것만 남긴다.
- 잡음 제거: 검색량 하한(기준어의 0.02%), 한 글자 키워드 제외.
- 테스트: `tests/test_youth.py`

## 4. 세대 확산 감지 + 적중률 — `diffusion.py`
- 연령 6그룹의 주간 추이를 **각자 자기 최고치 기준**으로 정규화 → 크기가 아니라 *언제* 뜨는지만 비교.
- 단계 판정: 확산 대기 / 확산 중(+N주) / 윗세대 상승 / 전 연령 동시 / 지나감 / 상시 관심.
  - 붐 판정(기준선 대비 1.6배), 불완전 주 제외, 얇은(검색량 적은) 연령 제외, "이미 꾸준한 10·20대" 판별.
- **과거 유행 7개로 검증**(하이볼·요아정·두쫀쿠·탕후루 = 확산형 / 먹태깡·포켓몬빵·러닝크루 = 동시형).
- **워크포워드 백테스트**: 과거 매주 그 시점까지의 데이터만으로 판정 → 이후 4·8주 실제 결과로 채점, 기저율 대비 lift.
  첫 측정: "확산 대기" 후 8주 내 윗세대 확산 40% vs 기저 21% (1.9배).
- 테스트: `tests/test_diffusion.py` (미래 데이터 미사용 검증 포함)

## 4b. 급상승 신호 — 측정해 보니 예측력 없음 (정직한 기록)
- 후보 4개를 10·20대 키워드 20개 × 42주로 비교: 갑작스런 급등은 1.0배(평균회귀), "3주 연속 증가"는 1.58배.
- **같은 규칙을 96주로 다시 재니 0.89배로 뒤집힘** → 첫 결과는 같은 데이터로 규칙을 고르고 채점한 과적합.
- 결론: "3주 연속 증가 / 반짝 급등"은 **설명용 라벨**로만 표시하고, 예측력은 매 실행 재측정 수치를 그대로 보여준다.

## 4c. 계절성 보정 — `diffusion.seasonal_adjust`
- 작년 같은 주 ÷ 작년 ±6주 평균 = 계절 계수 → 나눠서 방학·명절 같은 반복 변동 제거(장기 성장은 유지). 작년에 거의 없던 키워드는 보정 안 함.
- 추가 호출 없음(날짜 범위만 1년 연장). 측정(20개 키워드): "확산 대기" 8주 lift 1.31 → **1.53**, 4주 1.48 → 1.17 — 주력 8주 기준 채택, 표본 작음.

## 4d. 윗세대 정점 예측 — `bass.py`
- Bass 확산 모델(혁신 p·모방 q) "모양 전이"를 구현해 과거 확산형 4개(9개 연령)로 검증: 오차 평균 **3.4주**.
- 단순 규칙 "윗세대는 시작이 늦은 만큼 정점도 늦다": **2.7주** → **단순 규칙 채택**. Bass 는 10·20대 정점이 아직 안 왔을 때 추정에만 사용.
- 정점이 이미 지난 예측은 표시하지 않음(10·20대가 지금 붐일 때만).

## 3b. 베이지안 수축 — `youth.shrink`
- 배수^w, w = V/(V+K), K = 기준어의 0.05%(≈등산): 근거 적은 배수를 1배로 당김(하드 컷 대체).
- 측정(30개 키워드, 이번 주 vs 지난주): 순위 상관 0.97 → 0.97(동일), **Top5 일치 4/5 → 5/5**, "발로란트 강의" 같은 소수 검색이 Top5 에서 빠짐.

## 5. 카테고리 분류 — 무키(keyless) 증거 투표 — `categories.py`
- 트렌드에 분야 라벨을 주는 공개 소스는 없다 → **독립 증거 5종이 투표**:
  뉴스 섹션 헤드라인 언급 · 인기 영상 카테고리 · 위키백과 문서 분류(동음이의 문서 제외) · 쇼핑 분야 · 관련 기사-섹션 단어 겹침
  + 한국어 헤드라인형 트렌드("석유 최고가격 동결")를 위한 **자체 핵심어 사전**.
- 11개 분야 택소노미, 투표 내역(`category_votes`)을 남겨 라벨을 설명 가능.
- 테스트: `tests/test_categories.py`

## 7. 워치리스트·알림 — `alerts.py`
- 규칙은 **변화가 있을 때만** 발화(이전 상태를 저장소에 보관) → 같은 상태가 계속돼도 조용.
- 4종: 단계 진입 / 10·20대 2배 돌파 / 정점 4주 이내 / 관심 키워드 첫 등장.
- 출력: 암호화 카드 + **공개 RSS(feed.xml)** — 리더가 복호화할 수 없으므로 평문이지만 소스 이름은 넣지 않는다(테스트로 검사).
- `watchlist.txt` 키워드는 항상 추적 대상에 고정(카테고리 분산 규칙보다 우선).

## 8. 관심의 속도 — 교체율·쏠림 — `flux.py` (과거 데이터: `pageviews.py`)
나라마다 매일 나오는 **순위 목록**만으로 계산하는 서술 지표 두 개. 예측이 아니므로 과적합할 것이 없다.
- **교체율**: 오늘 상위 10개 중 어제 없던 항목의 비율. 근거: Iñiguez·Pineda·Gershenson·Barabási,
  *Dynamics of ranking* (Nat Commun 13:1646, 2022) — 새 항목 유입량이 순위 안정성을 결정하며,
  유입이 많으면 **상위권만** 안정적이다.
- **쏠림**: 그날 상위 10개가 가져간 조회 비중.
- **나라끼리 절대값을 비교하지 않는다.** 18개 언어로 직접 재보니 모수 규모와 쏠림이
  `r = −0.31`(e배당 −1.7%p)로 얽혀 있었다. 그래서 모든 수치는 **그 나라 자신의 최근 90일 중앙값 대비**로만
  공개한다(`flux.summary`). 하루 판정 임계값은 그 나라의 표준편차, 단 최소 5%p(`MIN_GAP`).
- **추이**: 1년 전 같은 길이 구간과 비교(`flux.trend`). Lorenz-Spreen 외 (Nat Commun 10:1759, 2019)는
  집단적 관심의 주기가 갈수록 짧아진다고 보고했는데, 우리 데이터에서도 그런지 직접 확인하기 위한 것.
- 과거 순위 목록은 **몇 년치를 소급 조회**할 수 있어(`pageviews.py`), 자체 아카이브가 며칠치뿐인 지금도
  첫날부터 동작하고 연령 데이터가 없는 나라에도 적용된다.

## 9. 유행의 모양 — `shapes.py`
정점 **앞뒤 일주일**에 관심이 어떻게 갈렸는지(전 / 당일 / 후 비율)만 남기고 곡선은 버린다.
Lehmann·Gonçalves·Ramasco·Cattuto, *Dynamical Classes of Collective Attention in Twitter*
(WWW 2012, 251–260)가 해시태그 402개에서 네 부류를 찾은 방법 그대로다(군집 수는 BIC·10겹 교차검증).
- **예고형**(정점 전에 달아오름) / **하루형**(당일 집중) / **대칭형**(오른 만큼 내려감) / **여운형**(뒤가 더 김).
- 한국어 위키 급등 223건 재현: 예고형 18% · 하루형 12% · 대칭형 37% · 여운형 32%.
- **교차 검증(중요)**: 라벨은 정점 ±7일만 본다. 그런데 **1년 뒤 재등장률**이 예고형 39%(32/82),
  대칭형 27%, 하루형 18%, 여운형 17%로 갈렸다(ko+ja 430건, z≈2.9). 라벨이 보지 않은 데이터를
  맞힌 것이므로 분류가 실체가 있다는 근거다 — Crane & Sornette (PNAS 105:15649, 2008)가
  감쇠 지수로 나눈 집단을 *정점 이전* 행동으로 검증한 방식과 같은 취지.
- 정점 뒤 일주일이 지나야 읽히므로, 갓 뜬 항목은 **라벨을 붙이지 않는다**(추측하지 않음).

## 9b. 수명 예측 — 측정해 보니 실패 (정직한 기록)
Berger & Le Mens (PNAS 106:8146, 2009)의 "빨리 퍼진 것이 빨리 버려진다"를 우리 데이터로 구현했다가
**기각**했다.
- 워크포워드 결과 평평한 기준선("보통 N일") 대비 리프트 **0.90~1.07** — 개별 항목의 수명을
  맞히는 힘이 사실상 없다(ko 336건·en 159건, 세 가지 급등 정의 모두).
- 집단 수준 효과도 정의에 민감했다. 엄격한 정의(단일·비반복·고립된 급등, n=59)에서는
  빠름 34일 / 중간 58일 / 느림 133일로 뚜렷했지만, 정의를 느슨하게 하면(모든 급등, n=186)
  24 / 35 / 31일로 사라졌다. **정의가 결론을 만든다면 그건 발견이 아니다.**
- Bentley & Ormerod (PNAS 106:E96, 2009)의 "대칭이라 그렇게 보일 뿐" 반론을 배제하지 못했다.
- 그래서 화면에 올리지 않았다. 모멘텀(4b)과 같은 처리 — 남는 것은 `shapes.bursts()` 급등 검출뿐.

## 6. 운영 장치
- 키 없는 경로 + 공식 API **자동 전환**(`segments.naver_modes`), 요청 페이싱·429 재시도.
- **조용한 실패 방지**: 배포 점검 → 경고 이슈 자동 개폐(`health.py`).
- **출처 비노출**: 공개 뷰에서 소스 식별자 제거 + 데이터 암호화(`publish.py`), 브라우저 E2E 로 누출 검사.
- **영구 기록**: KST 일별 요약을 `data` 브랜치에 커밋(`archive.py`) → 7일/30일 뷰와 백테스트의 기반.
