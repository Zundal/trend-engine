# 소비 탭: 지수 · 도표 · 추이 — 설계

## 왜
사용자는 **지금 무엇이 인기이고 사람들이 어디에 돈(관심)을 쓰는지**를 나이·성별·나라별로 보고 싶다.
숫자(지수·비중·변화율)와 그림(막대·선·열지도·표)으로 한눈에, 사람이 바로 읽게 **편집된** 형태로.
지금 소비 탭(뜨는 것·소비 키워드·세대 차이·나라 비교)은 목록과 문장뿐이고 추이가 없다.

## 목표 / 비목표 / 실패 기준
- 목표: 한국은 첫날부터 1년치 추이(주 단위) + 나이·성별 분야 비중. 6개국 모두 '지금 뜨는 것'의 분야 구성과
  나라 비교를 수치로. 우리 기록은 하루씩 쌓여 6개국 모두의 추이가 된다.
- 도표마다 결론 한 줄(자동 문장)을 위에 둔다. 강조 선은 3개까지, 나머지는 회색.
- 비목표: 인종별(공개 무키 자료 없음), 지출 금액(원) — 없는 걸 있는 것처럼 보이지 않는다.
- 실패 기준: 클릭 지수를 '지출액'이나 '그 연령 사람 중 몇 %'로 읽히게 쓰는 것. 페이지·데이터에 제공처 이름.
  12색 무지개 그래프. 모바일 가로 넘침.

## 접근 (검토한 것)
1. **우리 기록만** — 6개국 같은 방법이지만 추이가 몇 주 동안 비고, 나이·성별 지출 축이 한국 탭 몇 개뿐. ✗
2. **외부 지수(구글 트렌드 등)로 다른 나라까지** — 배포 서버(미국 IP)에서 막히거나 키가 필요. ✗
3. **(선택) 한국 = 포털 쇼핑 클릭 지수(키 불필요, 1년치, 나이·성별) + 6개국 = 순위표 읽기 + 우리 일별 기록** ✓
   사용자가 이 방향을 승인("진행해줘").

## 데이터
### 한국 쇼핑 클릭 지수 (`consumer/shopindex.py`)
- 업스트림: 포털 쇼핑 분석의 분야 클릭 추이(`getCategoryClickTrend`), 키워드 클릭 추이(`getKeywordClickTrend`).
  비공식 → 차례로·1초 간격, 429 면 물러남, 캐시. 배포 서버에서 같은 호스트(쇼핑 인기 검색어)가 이미 0 오류로 동작.
- 11개 분야(패션의류 … 도서). 한 요청에 분야 3개까지 → 기준 분야(패션의류) + 2개씩 5번 요청하고,
  기준 분야 합으로 배율을 맞춰 한 척도로 잇는다(`chain`).
- 그룹 21개: 전체 · 10대~60대+ · 여성 · 남성 · 나이×성별 12개. 그룹마다 5요청.
- 기간: 끝난 주만(일요일 끝, 오늘−2일 이전의 마지막 일요일), 57주(52주 그래프 + 작년 같은 4주 비교).
  주 단위라 같은 주 안에선 바뀌지 않는다 → 그룹별 캐시 키에 끝 날짜를 넣고 8일 보관. 한 번 실행에
  그룹 7개(35요청)까지만 받고 나머지는 다음 실행 → 한 주에 약 105요청.
- 계산(순수 `build`): 그룹별 최근 4주 분야 **비중**(%), 전체 대비 **배수**, **4주 변화**(직전 4주 대비 %),
  **작년 대비**(52주 전 같은 4주 대비 %), **지수 추이**(그룹 안 최댓값 = 100, 52주).
- 결론 문장(순수): 그룹마다 "20대 여성은 쇼핑 클릭의 31%가 패션의류 · 전체보다 화장품·미용을 1.9배 더 봐요",
  "최근 4주 가장 늘어난 분야는 식품(+18%), 가장 줄어든 분야는 …".
- 소비 키워드 상위 12개의 1년 클릭 추이: 키워드의 분야 → 쇼핑 분야 순서대로 5개씩 묻고, 빈 결과면 다음 분야.
  실행당 12요청까지, 키워드·주 단위 캐시(없음도 캐시).
- 오프라인: `tests/fixtures/consumer/kr-shopindex.json`(그룹 11개 원문), `kr-shopkw-trend.json`(키워드 원문).

### 우리 일별 기록 (6개국)
- 기존 스냅샷(목록 순위, 14일)과 별도로 작은 일별 요약 `consumer-day:{나라}:{날짜}` 400일 보관:
  키워드 점수 상위 40, 뜨는 것의 분야별 개수.
- 공개: `history = {days, fields}` → 분야 × 날짜 열지도. 한국 외 키워드 카드의 미니 그래프는 기록 3일부터.

### 나라 비교
- 나라별 '지금 뜨는 것'의 분야별 개수(`world.mix`) → 분야 × 나라 표(비중 %).
- '여러 나라에서 동시에'를 품목 × 나라 순위 표로.

### 오늘 요약 (순수 `trends.summary`)
- 한국: 가장 늘어난 쇼핑 분야 · 유독 많이 보는 분야(나이×성별, 비중 3% 이상 중 배수 최대) · 뜨는 키워드 · 여러 나라에서 동시에.
- 그 외: 지금 뜨는 것 개수 · 가장 많이 뜨는 분야 · 뜨는 키워드 · 여러 나라에서 동시에.

## 화면 (소비 탭, 위에서 아래로)
1. 오늘 요약 — 숫자 타일 4개.
2. (한국) 어디에 관심이 가나 — 나이 칩 · 성별 칩 → 결론 한 줄, 분야 막대(비중 %, 전체 비중 눈금, 배수),
   아래 열지도 표(분야 × 전체·나이·성별, 숫자 = 비중, 주황 = 전체보다 많이 / 파랑 = 적게, 머리 누르면 그룹 선택).
3. (한국) 분야별 1년 추이 — 같은 그룹 선택. 선 11개 중 강조 3개(파랑·주황·청록, 검증된 팔레트), 나머지 회색.
   끝 라벨, 마우스/터치 십자선 툴팁, 아래 표(지금 지수 · 4주 변화 · 작년 대비, 행 누르면 강조).
4. 뜨는 것 (그대로).
5. 소비 키워드 — 카드마다 지수(1위 = 100) + 미니 그래프(한국: 1년 쇼핑 클릭, 다른 나라: 우리 기록) + 4주·작년 대비.
6. 세대·성별로 다른 것 (그대로).
7. 나라 간 비교 — 분야 구성 표 + 동시 순위 표 + 이 나라에서만.
8. 우리 기록으로 본 흐름 — 분야 × 날짜 열지도(최근 14일). 기록 1일째면 그 사실을 적는다.
9. 분야별 순위 (그대로).

## 제약
- 공개 데이터·페이지에 제공처 이름 금지("포털 쇼핑 클릭"으로), 금지 키(`mode`, `anchor`, `errors` …) 피하기.
- `parse`·`chain`·`build`·문장·요약은 순수 함수, 테스트는 네트워크 없음.
- 지수는 '클릭 양'이지 금액·인원 비율이 아니다 — 화면 문구에 그대로 적는다.
- UI 변경 → e2e 갱신·통과, `--offline serve` 콘솔 에러 없음, 390px 가로 넘침 없음, 밝은/어두운 모드.

## 빌더 재량 (내 판단)
- 분야 순서·색: 강조 3색은 데이터 시각화 팔레트 1~3번(검증 통과), 나머지 회색.
- 차트는 의존성 없이 손으로 그린 SVG/HTML (기존 페이지 방식).
- 분야 필터 칩은 한국 쇼핑 지수 구역에 영향 없음(분류 체계가 다름).
